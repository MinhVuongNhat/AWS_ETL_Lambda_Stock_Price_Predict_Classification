#### Summary Report: "FCAJ Meetup #2 – Cloud Architecture, Security & Monitoring"

##### Event Objectives
- Continue deepening the community's understanding of AWS Cloud architecture and services.
- Share practical experiences in cloud security, application development, and SLA monitoring.
- Inspire participants through real-world cloud project case studies.

| Speaker | Topic |

---

#### Key Highlights

**1. Cloud Architecture & AWS Best Practices (Hoàng Trọng)**
- Deep dive into AWS Well-Architected Framework: the five pillars of Operational Excellence, Security, Reliability, Performance Efficiency, and Cost Optimization.
- Architecture design patterns for high-availability and fault-tolerant applications on AWS.
- Practical guidance on choosing the right AWS services for different workload types.
- Common architectural anti-patterns to avoid when designing cloud systems.

**2. Application Development on AWS Cloud (Đạt & Cường)**
- Building scalable web applications using AWS serverless services (Lambda, API Gateway, DynamoDB).
- Infrastructure as Code (IaC) using AWS CloudFormation or CDK to automate resource provisioning.
- CI/CD pipeline integration with AWS CodePipeline and CodeDeploy for continuous delivery.
- Strategies for handling state in stateless Lambda functions using DynamoDB and S3.

**3. AWS SLA Monitoring & Risk Assessment (Hiếu Nghị)**
- Understanding AWS Service Level Agreements (SLA) and uptime commitments across key services (EC2, RDS, Lambda, S3).
- Building a custom monitoring dashboard to track SLA compliance and detect anomalies in real-time.
- Student risk monitoring system: applying AWS monitoring concepts to track student performance metrics.
- Alert escalation strategy using Amazon CloudWatch Alarms and SNS notifications.

**4. FCAJ Project Sharing (Kiên & Thọ)**
- Community presentation of ongoing FCAJ intern projects: architecture overviews, progress updates, and blockers.
- Discussion of lessons learned and collaborative problem-solving among participants.
- Peer feedback sessions to improve project architecture and implementation approaches.

---

#### Key Takeaways

- **Well-Architected is non-negotiable:** Applying the five pillars of the AWS Well-Architected Framework from the start prevents costly refactoring later.
- **Infrastructure as Code accelerates delivery:** Automating infrastructure provisioning with CDK or CloudFormation ensures consistent, repeatable deployments.
- **SLA monitoring = business continuity:** Understanding AWS service SLAs and proactively monitoring them is critical for production workloads.
- **Peer learning is powerful:** Hearing other FCAJ teams' challenges and approaches provided fresh perspectives on our own architecture decisions.

---

#### Applying to Work
- Review our current Lambda + API Gateway + DynamoDB architecture against Well-Architected pillars (especially Reliability and Cost Optimization).
- Consider adding CloudWatch Alarms for API Gateway 5xx error rates and Lambda timeout metrics.
- Implement peer architecture reviews within our own team before finalizing the system design.
