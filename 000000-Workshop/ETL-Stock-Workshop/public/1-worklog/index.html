Work Log

Work Log

8-Week Project Log — Tracking detailed progress, deliverables completed, technical challenges encountered, and implemented solutions during the development of the AWS Big Data ETL Pipeline & Machine Learning Project.

Week Tasks & Deliverables Status Issues & Challenges Solutions & Key Takeaways
Week 1 Project Initialization & Ingestion Pipeline Setup• Setup Python environment (Polars, YFinance, Boto3).• Develop ingestion script fetching NASDAQ stock data via Yahoo Finance API (yfinance).• Store initial Raw Data in CSV/Parquet format. Completed • Ingesting over 3,000 tickers using pandas was extremely slow.• Yahoo Finance API hit rate limits and frequent request timeouts. • Migrated to Polars for data processing (10–50x speedup over Pandas).• Implemented asynchronous batch processing and chunking.
Week 2 AWS Cloud Architecture & S3 Bucket Layering• Configure AWS IAM roles and S3 Bucket hierarchy.• Design 4-tier storage architecture: raw/, cleansed_daily/, processed/, quarantine/.• Build s3_service.py utility module for S3 interaction. Completed • Complexities in organizing historical Parquet data spanning from 1962 to present.• High S3 read/write IOPS and storage costs. • Partitioned historical dataset by year (processed/YYYY.parquet) for query optimization.• Utilized Snappy-compressed Parquet format to minimize storage footprint.
Week 3 Data Quality Gate & Quarantine Mechanism• Develop validator.py for schema and data quality verification.• Build quarantine.py to isolate corrupted or invalid data.• Package and deploy lambda_quality_gate.py. Completed • Ingested data contained anomalies: missing values (null/NaN), negative prices, duplicate dates, missing trading days.• Dirty data leaked into main pipeline, corrupting technical indicator calculations. • Defined strict Data Quality Gate rules.• Automatically routed invalid records to quarantine/ S3 prefix with detailed error logs without breaking the pipeline execution.
Week 4 Feature Engineering Engine Development• Design transform.py computing 16 technical indicators using Polars.• Indicators: SMA (10, 20, 50), EMA, RSI, MACD, Bollinger Bands, Volatility, Price Lags.• Define classification target label (Target_Return_1D_Class). Completed • Complex time-series window functions handling missing trading days.• Risk of Look-ahead Bias (data leakage from future prices). • Applied Polars Window functions partitioned by Ticker and strictly ordered by Date.• Audited shift/lag logic to ensure technical features rely strictly on historical data.
Week 5 Serverless Fan-Out Architecture (AWS SQS & EventBridge)• Implement lambda_daily_collector.py (Producer) reading tickers.json and sending SQS messages.• Implement lambda_collector_producer.py (Consumer) processing SQS messages to fetch data.• Configure AWS EventBridge Cron for automated daily orchestration. Completed • AWS Lambda hit the 15-minute timeout when downloading data for 3,000+ tickers sequentially.• Partial consumer failures caused data chunk loss. • Implemented Fan-Out Pattern: Producer Lambda splits tickers into small chunks (e.g., 50 tickers) and pushes to AWS SQS Queue.• Multiple Consumer Lambdas execute in parallel.• Configured Dead Letter Queue (DLQ) for failed message handling.
Week 6 Machine Learning Model Training (XGBoost Classifier)• Write train_model.py script to train price movement direction classifier (Up/Down).• Perform Time-series data splitting (Train/Validation/Test).• Evaluate model performance (Accuracy, Precision, Recall, AUC, Feature Importance) and export training_report.md. Completed • Class imbalance between bullish and bearish trading days.• Risk of overfitting on historical market regimes. • Employed TimeSeriesSplit cross-validation instead of standard random K-Fold.• Fine-tuned XGBoost hyper-parameters and adjusted scale_pos_weight.• Uploaded trained model artifact (xgboost_v1.json) to S3.
Week 7 Predictor Service Deployment (AWS Lambda & API Gateway)• Implement lambda_stock_predictor.py loading model from S3 for real-time inference.• Connect Lambda with AWS API Gateway to expose RESTful endpoints.• Automatically compute Top 5 Recommended Stocks (highest win-rate probability). Completed • Lambda deployment zip package exceeded limits due to heavy dependencies (XGBoost, Scikit-Learn).• Cold start latencies degraded API response time. • Packaged Lambda using Docker Container Image hosted on Amazon ECR.• Optimized Docker image layers to minimize cold start time.
Week 8 Web Dashboard, Simulation Replay Engine & Workshop Documentation• Build interactive Streamlit Dashboard (streamlit_app.py).• Develop Replay Engine (run_replay_local.py, lambda_replay_*) for market data simulation.• Write comprehensive Workshop docs, README, and perform End-to-End system verification. Completed • Synchronizing real-time data flow between API Gateway and Streamlit UI.• Simulating daily market stream for pipeline verification without waiting for live market open. • Designed stateful Replay Engine storing simulation state in S3 to replay data step-by-step.• Formatted step-by-step Workshop documentation for easy hands-on execution.
